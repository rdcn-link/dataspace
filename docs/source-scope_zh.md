# 源码发布范围

[English](source-scope.md)

快照日期：2026-11-22（北京时间）。科诺空间当前源码来自本地前后端分离工程；DACP/XStream 来自本地维护的 platform-source 源码。OIDC、TDS、AI-DataSeek、dataset-vfs、S3 来自关联后端工程；4fair-web 作为参考前端收录。科学源码来自 service-design，包含后续批量分析实现。

采用全新提交历史，不带入各工程旧 .git 历史和排查工作目录；保留组件原有声明。保留公开界面使用的静态图片资源；排除科学成果存储、实体数据、数据库导出、验收截图、部署备份、账号名单和私有连接文件。含真实账号或凭据的一次性数据库写入/维护测试文件不纳入公开仓库。

仅在发布副本中的整理：Java Mongo/微信配置外置，示例凭据和票据替换，科学清单路径可配置，算子测试清单移入源码夹具，补充文档及忽略规则。本次发布没有改动正在运行的正式/测试服务。现存运行路径和默认值在说明中列出，不宣称已具备通用的一键部署包。
