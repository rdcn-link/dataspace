# Dataset exploration availability

An explicit `isAiExploration:0` (numeric or string) blocks exploration for every data center. Cards and detail pages use the shared `ConetDatasetUI.seek` button. It is natively disabled, visually unavailable and has `aria-disabled=true`; its tooltip and accessible label consistently explain “暂未开放智能探查服务”. There is no click handler or toast, login prompt, new window or submission. The backend enforces the same rule before acquiring a center token or posting a submission. Existing ScienceDB positive-flag requirements remain unchanged; this change does not globally reinterpret missing legacy flags.

TPDC submissions use the dataset metadata's `path` through the internal mapping service. Do not substitute another directory to work around center inventory, filename or output-size limits. The public metadata projection still excludes server paths. A successful inventory submission is not a scientific analysis or evidence of data-center approval for application computation.

The 2026-11-24 production review checked all 577 published TPDC records, using bounded concurrency and a retry for communication/server failures. 570 succeeded and 7 failed. A protected server-side EJSON backup precedes the update; only `tds.tds-dataset.isAiExploration` is changed, with compare-and-set predicates for the original source, publication status, path and flag. Successful records are set to1 and failed records to0; concurrent changes are not overwritten. All577 flags and path hashes were rechecked afterward; seven blocked requests returned409 without a center submission. The solar-radiation dataset remains closed because the center inventory output exceeds its size limit.

Before re-enabling a failed dataset, resolve the center-side issue or correct its authoritative metadata path and verify a fresh submission. Do not enable it merely to remove the unavailable hint. Restoring older flag values requires the protected backup and a targeted database update, not replacement of whole metadata documents. Backups, detailed checks and reports live under `/mnt/data/conet-seek-policy-backups/`; credentials and SSO tokens are never included in the reports or source repository.
