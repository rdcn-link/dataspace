# 数据智能探查可用性

所有数据中心的数据集，只要`isAiExploration`明确为数字0或字符串“0”，均阻止探查。卡片与详情页复用`ConetDatasetUI.seek`按钮，使用原生disabled禁用属性、不可用样式和`aria-disabled=true`，统一通过悬停提示与无障碍标签说明“暂未开放智能探查服务”。不绑定点击操作、不显示点击toast，不弹登录、不新开窗口、不提交请求。后端在获取中心令牌或提交之前执行同样校验。科学数据银行原有的正向开通标记要求保持不变，不将其他中心缺失的旧字段一律解释为关闭。

青藏高原提交通过内部映射服务使用数据集元数据的`path`。不能为了绕过中心目录清单、文件名或输出大小限制而替换目录。公开元数据仍不暴露服务器路径。目录提交成功不是科学分析，也不代表已获得应用计算的数据中心审批。

2026-11-24正式全量验证了577条已发布青藏高原记录，使用有界并发，对通信或服务端失败重试；570条成功、7条失败。先保存受保护的服务端EJSON备份，仅修改`tds.tds-dataset.isAiExploration`，用原来源、发布状态、path及旧标记进行比较更新，不覆盖并发改动。成功设为1、失败设为0。完成后逐项复核577个标记及path哈希；7个关闭项的后端请求均返回409且未提交中心。太阳辐射数据因中心目录清单输出超过上限而保持关闭。

失败项重新开放前，应处理中心侧问题或修正权威元数据路径，再实际验证提交；不能仅为了去除不可用提示而改为1。回退旧标记应使用受保护备份做针对性更新，不整份覆盖元数据。备份、逐项记录及报告位于`/mnt/data/conet-seek-policy-backups/`，报告和源码仓库均不包含凭据或SSO令牌。
