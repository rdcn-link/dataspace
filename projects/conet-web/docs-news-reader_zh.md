# 资讯阅读页与数据集关联

资讯卡片继续在新窗口打开托管文章。公开资讯接口增加封面及由 `tds-information.cstr` 明确标识得到的关联。匹配到已发布 `tds-dataset` 时，链接指向具体元数据ID；未匹配的标识提供精确目录检索。不会用标题相似或来源中心关系伪造数据集关联。文章侧栏也保留正文中明确给出的数据服务链接。

使用 Node.js22 和仅构建时需要的 Cheerio 生成兼容的缓存微信文章：

```sh
npm ci
npm run build:news -- --input /tmp/news-originals --metadata /tmp/news-metadata.json --output /tmp/news-generated
```

元数据为公开字段数组：`_id`、`name`、`description`、`source`、`url`、`coverUrl`、`cstr`、`updateAt`。不要传入账号记录、凭据或微信消息服务标识。生成器输出HTML、带校验的部署清单和内容保留报告；文章及部署清单属于运行内容，不作为源码提交。

阅读页复用 `/news-reader.css`、`/news-reader.js`、网站导航和现有风格设置，统一字体排版、章节导航、图片放大、来源信息及手机布局。生成成功前逐篇比对正文文字、图片地址和顺序，不重绘原图。缓存中的视频引用改为明确的原文视频链接。清单保留原文件哈希，其他会话修改文件后部署将停止。

网站应将 `/datasetFile/` 指向现有资料根目录。部分文章在嵌套目录中，应把公开文章目录前缀映射到实际存档位置，保留相对图片和样式路径；不要直接平铺目录或静默补写文章。未来若确需元数据摘要回退，页面必须明确标注为摘要。2026年11月这次199页推广未生成摘要替代页。

用户中心用“工作台”承载个人业务概况，“分析统计”承载分析图表，菜单分为个人资料、分析与成果、申请与审批、平台管理。继续按原有能力权限决定菜单显示，改名与分组不授予权限。
