# 科诺空间前端

对外品牌为“CONET｜科诺空间”。页头保留CONET，中文副标题使用科诺空间；行业可信数据空间作为产品定位用于说明文字。页面标题、应用/成果署名继续使用科诺空间。

## 本轮精细化调整（2026-11-18）

首页说明：在可信数据空间中，让各中心的数据按授权参与分析，发现数据、运行应用、分享成果，一站完成。

首页UNION图使用目录中真实登记的5个中心的简称和领域：青藏高原数据中心、科学数据银行、昆明动物数据中心、化学化工数据中心、基础学科数据中心。每个方框可进入对应来源的数据目录；完整名称通过提示和无障碍标签提供。图是协作示意，不表示5个中心都已联网或获准计算。中心简称和领域由本轮目录快照核对，并非实时联网状态。

保持原有导航入口、数据智能机器人入口和业务交互。本轮不改登录、审批、任务、发布规则或任何科学成果。

## 本地开发与提交

- `public/` 是可维护前端源文件，`dist/` 由 `npm run build` 生成；构建前已对齐90.48实际在用版本，避免旧源码覆盖线上修复。
- `server.mjs` 和 `backend/` 是前端站点的代理与会话网关代码；配置文件和密钥保持在站点源码之外。
- `npm run check` 检查页面路由和代理；`npm run build` 生成发布目录。
- 本轮部署逐文件校验线上SHA256，保存备份后同步`public/`与`dist/`，静态文件更新不重启分析服务。
- 后续仓库应提交源码、构建脚本和文档；不提交运行配置、数据库连接、会话密钥、审计备份、`node_modules/`或分析成果目录。

本轮修改清单、部署基线、浏览器验收与源码包校验值保存在工作区`brand-refinement/`。收到仓库地址后再进行首次提交，不擅自创建远程仓库或推送。

## 动态接入名录更新

首页不再写死5个中心。`/api/metadata/hub-showcase`从MongoDB读取全部登记数量和`isAccess:1`的中心全称。四个外围节点每2秒随机轮换一个，每30秒刷新名录，支持暂停、悬停和减少动态效果。当前真实数据为30个登记中心、5个已标记接入；30节点扩展场景仅在隔离的浏览器样例中验证，没有修改真实接入状态。

当前状态（2026-11-18）：根据用户反馈，首页已恢复上一版固定五中心协作图，停止加载动态轮播脚本；页头保留CONET｜科诺空间。上述动态名录说明记录的是已停用的试验实现。

首页四项统计通过`/api/metadata/platform/homepage-metrics`从数据库读取：接入中心、原始数据集加已发布分析产品、实体数据验证应用、持久化分析任务。复用MongoDB独立`conet.tasks`，每30秒刷新，不以页面常量或内存累加。历史案例不自动计为已发布数据产品。
