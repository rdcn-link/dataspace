# 科学应用库范围

2026-11-24对原有60项平台设计进行整体审查，依据科学用途判断，不依据文件扩展名。以Excel/CSV存放科学实验数据的千粒重、疲劳曲线拟合、分组汇总及质量审计等应用继续保留。

`application-curation.mjs`记录审查后的排除项：`svc-008`“科研文档结构与要素提取”处理DOCX文档，不纳入科学数据分析应用库。其余59项平台应用保留，其中29项已有实体数据验证；这一数量不表示其余设计已经可执行。

启动时将排除项在MongoDB中标为`catalogIncluded:false`、`status:offline`、`executable:false`，保存理由和审查日期。公开应用列表及App Builder包含下线项的列表都排除它，旧设计列表和汇总遵循相同范围。普通状态接口不能重新上架被排除的应用。原定义、版本、任务、成果、产品发布权限和科学图片均保留。筛选策略独立于不可覆盖的科学定义，不改写发布内容哈希。

对所有保留的已验证应用使用独立副本测试：算子可用性、真实XStream定义加载和导出、修改流程名称回传、MongoDB保存重载、程序包导出。测试结束删除自身草稿，不提交科学计算。浏览器抽测覆盖旬降水、疲劳分析和CTD；NPP已有完整浏览器证据。

正式部署前，将原`svc-008`登记及历史任务、成果标识和内容哈希备份到`/mnt/data/conet-refinement-backups/curation-before-20261124.json`，权限600。如需回退，移除排除策略后，应从该备份恢复状态与筛选字段；只回退源码不会撤销已持久化的下架状态，不应整份覆盖历史业务文档。

紧凑目录仍默认每页12条，保留24/48条选择及分页。卡片保留标题、两行摘要、来源、大小或时间、收藏/浏览/下载统计和常用操作；CSTR、DOI及版本留在详情页。仅目录采用紧凑间距：常规桌面三列、大屏四列、平板两列、手机单列。资讯卡片和详情页间距不变。静态部署仅注入一次登录脚本，动态网关沿用既有注入逻辑。
