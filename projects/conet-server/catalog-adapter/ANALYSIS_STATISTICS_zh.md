# 分析统计

用户中心分为数据智能探查、应用服务分析两个页签。图表使用本地部署的 Apache ECharts 5.6.0 common 包，原 LICENSE 和 NOTICE 保留在 `conet-web/public/vendor/`。

## 权限

所有请求都要求经过网关验证的登录会话。全平台权限沿用配置的平台管理员 UID 清单和经 OIDC 核实的角色共同确定的管理员标识。中心管理员通过 `tds-datacenter.adminUid` 识别，只能查看其登记管理的数据中心；切换到仅本人也不能移除此中心限制。普通用户只能查看本人记录。浏览器传入的用户标识不决定当前登录身份。

`GET /api/metadata/platform/user-center/statistics` 支持 `kind=exploration|applications`、`scope=all|center|self`、`center`、`user`（应用用户维度）、精确 `tool`/`dataset` 筛选、`start`/`end`、`grain=day|week|month`、`page`/`pageSize`（最多100）。无效或越权范围会拒绝。图表和明细使用同一套授权、筛选后的记录。本次不新增统计记录、索引或数据库表。

## 来源与口径

探查统计读取 `tds.analysis-tool-statistics`。优先采用具体的 `dataName`，缺失时关联 `tds-analysis-tool`，再使用已记录的工具名称或标识。数据集标题保留既有字段拼写 `datasetTittle`。缺失名称明确显示为未记录，不虚构。未明确归属的上报来源与已登记中心数量分开计算。

应用统计读取带有执行记录的 `conet.tasks`。从资源快照、审批中心标识和 `resource_bindings` 的元数据中心关联识别数据归属，不把模拟执行节点名称当成数据所属中心。缺失归属保持未记录。全平台任务总数按任务去重；跨中心任务在每个参与中心各计一次，因此中心参与次数之和可能大于任务总数。用户与中心维度可以在权限范围内独立筛选。

时间使用北京时间，周从周一开始。无调用的时间段填0，不插值生成调用。无效时间不进入趋势图但保留在总数中。默认全部时间，自定义日期最多一年。排行榜显示前10项；饼图其余项目合并为其他，总量保持一致。明细默认每页20条。

页签切换或布局变化时释放、调整图表。标签使用文本、提示使用画布富文本。不在前端保存认证票据，也不依赖外部图表 CDN。接口统计的是已反馈的调用记录，不把调用记录直接认定为外部科学分析成功。
