# 化学化工数据中心探查绑定

化学化工提交接口为`https://chemdc.fairspace.cn/api/v1/datasets/submissions`，携带身份的落地页面为`https://chemdc.fairspace.cn/dataset/seek/{返回标识}`，两者是同一流程的不同环节，不能混为同一个提交接口。

资源标识使用元数据的`external_id`。当前MongoDB导入记录将该业务标识保存于`datasetId`（例如`39f1871350684505903d8727626759dd`），适配器将其映射为提交字段`external_id`，不能用MongoDB的`_id`替代。旧记录只有在既有中心配置中按业务标识或标题唯一匹配时才能取到标识；配置只提供标识，不再覆盖存储目录。

`chemicalSeekBinding`依据元数据`updateAt`，按北京时间计算目录：

| 更新时间年份 | 目录 |
| --- | --- |
| 2026 | `/mnt/instdb/resourcesFile2026/{external_id}` |
| 2025 | `/mnt/instdb/resourcesFile2025/{external_id}` |
| 其他年份 | `/mnt/instdb/resourcesFile/{external_id}` |

更新时间缺失、无效，或标识不符合规范时明确拒绝，不猜测其他年份、路径或数据集。内部查询读取`external_id`与`path`，公开数据详情不暴露服务器路径。青藏高原仍使用自身元数据的`path`，化学化工年份规则不用于其他中心。

批量验证采用有界并发，对通信、服务端错误和限流重试，使用已核实的平台管理员身份提交。更新前在受保护的服务端目录备份原始元数据，只修改`isAiExploration`：成功为1、失败为0；以原标识、来源、发布状态、更新时间和旧标记进行比较更新，不覆盖并发修改。不改写原始更新时间、标识、实体路径或文件。

网站统一对零标记使用原生禁用按钮，列表和详情的悬停提示、无障碍说明均为“暂未开放智能探查服务”，不再保留点击toast的另一套效果。后端零标记拦截保持不变。失败项应修复并重新验证成功后再开放；目录提交成功不表示科学应用已经运行，也不代表已获计算审批。
